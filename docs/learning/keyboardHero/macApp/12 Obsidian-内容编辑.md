# 在 Obsidian 中练习内容编辑

先[启用 Vim 模式](./10%20Obsidian中的vim.md)，再在可丢弃的笔记副本中练习，避免覆盖重要内容。

## 操作

在编辑视图中准备下面两行：

```text
今天学习 Vim
明天继续练习
```

1. 按 `Esc` 回到 Normal 模式，用 `j`、`k` 在两行之间移动。
2. 在第一行按 `A`，输入句号，再按 `Esc`。
3. 按 `u` 撤销刚才的修改，确认句号消失。
4. 在一行中按 `i` 进入 Insert 模式，为文字添加内容，再按 `Esc`。

完成标志是：能够主动切换输入与移动，修改后能撤销。若操作与预期不符，先检查编辑区焦点、当前模式和快捷键冲突。
