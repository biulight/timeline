# 用命令面板管理 Obsidian 笔记

Vim 模式负责编辑笔记内容；新建、打开和重命名文件，使用 Obsidian 的命令面板更容易发现可用操作。

## 操作

1. 确认 **设置 → 核心插件 → 命令面板** 已启用。
2. 按 `Ctrl+P`（macOS 为 `Cmd+P`），输入想执行的命令关键词，例如新建笔记或重命名。
3. 用方向键选择命令，按 `Enter` 执行；不执行时按 `Esc` 关闭面板。
4. 常用命令可在 **设置 → 快捷键** 中搜索并绑定。命令面板会显示已经分配的快捷键，实际按键以自己的配置为准。

先在练习笔记上完成一次新建和重命名，确认文件列表及笔记标题同步变化。删除操作会影响真实文件，练习时不要选择重要笔记。
